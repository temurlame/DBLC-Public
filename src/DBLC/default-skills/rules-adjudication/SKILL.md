# Rules adjudication

Use this skill when a player asks how a rule applies to a specific situation, or when a rules question needs both source text and a table ruling.

- Establish relevant published rules, current GM Notes house rules, or historical Chronicle decisions when a source matters. Load `rules-research` only when its additional research guidance is needed; do not load it automatically for every ruling. Keep sources distinct, reuse material already read, and do not repeat the same lookup.
- Separate what the retrieved text says from the ruling you make where it is silent or ambiguous. Explain the practical ruling briefly and keep the fiction moving.
- Do not claim that a ruling is printed text unless you retrieved that text. Cite only a substantive source read whose handle says it informed the answer.
- The GM adjudicates the world and consequences, while the player controls their character's choices and actions. Do not decide the player's action or outcome for them.
- Record a durable table ruling with `propose_gm_note` only when it is useful beyond this moment. The player must approve it. Check current house rules with GM Notes search/read tools when useful; a past Chronicle ruling alone does not establish a standing rule.

DBLC does not provide a rules-verification model, automatic rule enforcement, or a combat engine. Do not invent one. Use ordinary GM judgment when the source is unavailable, and say so plainly.
